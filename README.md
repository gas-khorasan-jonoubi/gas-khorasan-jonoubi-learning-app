# دانستنی‌های گاز

برنامهٔ مستقل Flutter برای مرجع آموزشی و کتابخانهٔ آفلاین کارکنان شرکت گاز خراسان جنوبی.

## امکانات شاخهٔ توسعه

- نام نمایشی Android: «دانستنی‌های گاز»
- ورود مستقیم پس از صفحهٔ آغازین؛ بدون نام کاربری و رمز عبور.
- صفحهٔ آغازین با پوستر تأییدشده؛ تصویر کامل و بدون برش نمایش داده می‌شود و سه عبارت «شرکت گاز خراسان جنوبی»، «شهرستان عشق آباد» و «اداره گاز عشق آباد» زیر آن قرار دارند. زمان سه‌ثانیه‌ای پس از آماده‌شدن تصویر آغاز می‌شود.
- داشبورد، آموزش‌ها، راهنمای استفاده، کتابخانهٔ آفلاین متنی با جست‌وجو و فیلتر حوزه‌های کاری، و سوابق آزمون.
- ۲۰ آزمون مستقل آفلاین، هرکدام با ۴۰ سؤال چهارگزینه‌ای؛ زمان هر آزمون ۲۰ دقیقه (۳۰ ثانیه برای هر سؤال)، امکان جابه‌جایی و اصلاح پاسخ تا پایان زمان، و نمایش پاسخ‌های درست، نادرست و بی‌پاسخ.
- خرید یک‌بارهٔ دسترسی دائمی و مسیر بازیابی خرید کافه‌بازار؛ فعال‌سازی واقعی منوط به ثبت شناسهٔ برنامه، شناسهٔ محصول و کلید عمومی معتبر کافه‌بازار است.

## حجم و دارایی‌ها

پوستر اصلی تأییدشده برای بازتولید در مخزن نگهداری می‌شود. گردش‌کارها آن را به WebP با کیفیت ۹۲ تبدیل می‌کنند و فقط نسخهٔ فشرده در بستهٔ برنامه قرار می‌گیرد. کیفیت ۹۲ برای خوانایی نوشته‌های کوچک پوستر حفظ شده است.

## وضعیت محتوا

محتوای متنی و بانک پرسش فعلی، عمومی و پایه هستند و جایگزین دستورالعمل رسمی شرکت گاز نیستند. فایل‌های مصوب PDF، Word، Excel، تصویر و ویدئو هنوز دریافت و به کتابخانه افزوده نشده‌اند. مطالب فنی و ایمنی باید پیش از استفادهٔ عملی با آخرین دستورالعمل‌های رسمی و نظر مسئول ذی‌صلاح تطبیق داده شوند.

## کنترل کیفیت و ساخت APK

- گردش‌کار GitHub Actions با نام Flutter quality checks وابستگی‌ها، پیکربندی میزبان Android، آیکون، تحلیل کد و آزمون‌های خودکار را بررسی می‌کند. آزمون تصویری یک APK موقت debug را روی شبیه‌ساز Android نصب و اجرا می‌کند؛ این APK خروجی انتشار نیست.
- گردش‌کار GitHub Actions با نام Android release APK برای ساخت APK انتشار امضاشده تعریف شده است. اجرای انتشار به هفت GitHub Repository Secret نیاز دارد: چهار مقدار امضای Android و سه مقدار واقعی کافه‌بازار. مقادیر محرمانه فقط باید در GitHub Secrets نگهداری شوند، نه در مخزن یا چت.
- سه Secret کافه‌بازار عبارت‌اند از BAZAAR_APPLICATION_ID، BAZAAR_LIFETIME_PRODUCT_ID و BAZAAR_RSA_PUBLIC_KEY. شناسهٔ برنامه باید با شناسهٔ بستهٔ Android هماهنگ باشد؛ شناسهٔ محصول و کلید عمومی باید از پنل/مستندات معتبر کافه‌بازار دریافت شوند.
- APK انتشار فقط پس از تکمیل Secretها، اجرای موفق گردش‌کار انتشار و تأیید امضای فایل تولیدشده قابل تحویل است.
- خرید و بازیابی واقعی باید با حساب آزمایشی کافه‌بازار و دستگاه Android واقعی نیز آزمایش شود.

## نسخه

نسخهٔ تعریف‌شده در pubspec.yaml ملاک نسخهٔ کد است.

این شاخهٔ توسعه تا زمان بررسی و ادغام Pull Request مربوطه، لزوماً همان کد شاخهٔ اصلی main نیست.
