# اپلیکیشن آموزشی آفلاین شرکت گاز خراسان جنوبی

نسخه آغازین پروژه Flutter برای Android.

## تصمیم‌های پایه
- صفحه آغازین ۵ ثانیه‌ای با عناوین «شرکت گاز خراسان جنوبی» و «اداره گاز شهرستان عشق‌آباد»
- بدون نام کاربری، رمز عبور و ثبت‌نام
- طراحی رسمی با طیف رنگ آبی
- قابلیت استفاده آفلاین
- آزمون چهارگزینه‌ای نمونه و ذخیره نتایج روی همان گوشی
- بخش‌های آموزش و کتابخانه دیجیتال

## وضعیت فعلی
این commit اسکلت اولیه و نمونه قابل توسعه برنامه است. پرسش‌ها و متن‌های آموزشی فعلی صرفاً محتوای نمونه‌اند و نباید به‌عنوان محتوای رسمی یا تأییدشده شرکت تلقی شوند. فایل‌ها و منابع رسمی کتابخانه هنوز وارد نشده‌اند.

## ساخت APK
پروژه با Flutter ساخته می‌شود. فایل codemagic.yaml گردش کار ساخت APK نسخه Release را تعریف می‌کند. خروجی مورد انتظار:
build/app/outputs/flutter-apk/app-release.apk

## اجرای محلی
flutter pub get
flutter analyze
flutter run
