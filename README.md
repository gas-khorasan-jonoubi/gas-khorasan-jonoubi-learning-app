# آموزش شرکت گاز خراسان جنوبی

## تغییرات این نسخه
- صفحه شروع با پوستر رنگی تأییدشده نمایش داده می‌شود؛ تصویر کامل و بدون برش روی صفحه قرار می‌گیرد.
- زمان نمایش صفحه شروع دقیقاً ۳ ثانیه است و سپس برنامه مستقیم وارد داشبورد می‌شود.
- آیکون Android از تصویر مستقل NIGC با شعله آبی، قاب طلایی و نوشته طلایی NIGC تولید می‌شود.
- نام فارسی برنامه در Android برابر «آموزش شرکت گاز خراسان جنوبی» است.
- ورود اجباری یا صفحه رمز عبور اضافه نشده است.

## اضافه کردن دو تصویر تأییدشده
برای راحتی بارگذاری با گوشی، فقط فایل `gas_assets_for_github_upload.zip` را در ریشه مخزن و در همین شاخه قرار دهید. گردش‌کار Codemagic و GitHub Actions آن را خودکار استخراج می‌کنند.

محتویات ZIP پس از استخراج:
- `assets/app_icon.jpg` — دقیقاً تصویر شعله آبی و NIGC که کاربر فرستاده و انتخاب کرده است.
- `assets/splash_poster.webp` — پوستر رنگی شرکت گاز برای صفحه شروع سه‌ثانیه‌ای.

## ساخت APK
پس از قرار دادن ZIP و ادغام Pull Request شماره ۱، گردش‌کار GitHub Actions به‌طور خودکار APK Release را می‌سازد و در بخش Artifacts قرار می‌دهد. در Codemagic نیز گردش‌کار `android-release` همین مراحل را اجرا می‌کند.

خروجی:
`build/app/outputs/flutter-apk/app-release.apk`

محتوای آموزشی و پرسش‌های فعلی نمونه‌اند و تا زمان ورود و تأیید اسناد رسمی نباید به‌عنوان محتوای رسمی شرکت تلقی شوند.
