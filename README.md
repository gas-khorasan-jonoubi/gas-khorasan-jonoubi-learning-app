# دانستنی‌های گاز

برنامهٔ مستقل Flutter برای ساخت یک مرجع آموزشی و کتابخانهٔ آفلاین کارکنان شرکت گاز خراسان جنوبی.

## تصمیم‌های اصلی پروژه
- نام نمایشی برنامه: «دانستنی‌های گاز»
- بدون صفحهٔ ورود، نام کاربری یا رمز عبور
- شروع برنامه با صفحهٔ آغازین تمام‌صفحه و زمان نمایش ۳ ثانیه
- استفادهٔ آفلاین از محتوای بسته‌بندی‌شده در خود برنامه
- نگهداری نتایج آزمون روی دستگاه

## وضعیت فعلی
این مخزن هنوز اسکلت اولیهٔ برنامه است. صفحه‌های آموزش و کتابخانه در حال حاضر نمونه‌اند و محتوای رسمی و تأییدشدهٔ شرکت، بسته‌های PDF/Word/Excel و ویدئوها هنوز تکمیل و در برنامه قرار نگرفته‌اند. بانک پرسش فعلی نیز فقط چند سؤال نمونه دارد و هنوز آزمون زمان‌دار نهایی محسوب نمی‌شود.

## ساخت
گردش‌کار Codemagic در فایل `codemagic.yaml` تعریف شده است. ابتدا باید وابستگی‌ها دریافت و تحلیل/آزمون‌های پروژه اجرا شوند؛ ساخت APK فقط پس از تکمیل و تأیید مراحل لازم انجام می‌شود.
